Conhecendo o DOM

O que é o DOM?

DOM significa Document Object Model .

É uma representação do documento HTML em forma de objetos, organizada em uma estrutura hierárquica de árvore, conhecida como DOM Tree.

Funciona como uma espécie de árvore genealógica.

Note que cada elemento do HTML está conectado. Chamamos esses elementos de nó(node) dentro dessa estrutura.

Em outras palavras, o navegador transforma o HTML em uma estrutura que o JavaScript consegue acessar.

Pra que serve o DOM?

O DOM permite que o JavaScript interaja com os elementos HTML. Exemplos:

  • Selecionar elementos : Encontrar um botão
  • Alterar conteúdo : Alterar um título, paragráfo...
  • Alterar estilos : Mudar cores, aplicar bordas e qualquer outro estilo do css
  • Criar elementos : Criar listas, links, paragrafos...
  • Remover elementos : Excluir itens criados e já existentes
  • Capturar eventos : Detectar cliques, teclas pressionadas
  • Modificar atributos : Alterar um src, atributos aria e outros de modo geral...
